# Understanding Map for DeepSeek Harness

独立的 Harness 原生插件，包名 `@local/understanding-map-deepseek`。源码与现有 Codex 版本分开。

## 功能

- 聊天标题栏提供「理解地图」按钮，在 Harness 右侧打开原生 React 面板。
- 顶部常驻五类标签筛选与发言数量，可多选并显示匹配任一选中标签的发言。「全部」或「清除筛选」恢复完整地图。两种视图共用筛选选择，并按聊天保存。
- 「按层级」按话题组织可折叠大纲，编号保留原始发言顺序。
- 「按层级」筛选后隐藏空分支，保留匹配内容所在的祖先话题标题。
- 「按时间」使用与 Codex 端相同的节点样式和 22px 层级缩进。连续未匹配发言折叠为「已隐藏 N 条」，标明原始序号范围；点击展开后以较淡样式显示，仍可点击定位。灰色虚线连接时间顺序，蓝色实线仅连接原本存在且当前可见的承接两端。
- 话题的概念层级决定横向位置和蓝色深浅。顶层靠左、深蓝，子层向右、颜色变浅。
- 筛选后原始序号、横向层级与蓝色深浅保持原样。筛选、展开和收起使用本机已有地图，不调用模型、不消耗模型 Token，也不修改摘要、层级或原文定位标识。没有标签的发言在「全部」中显示。
- 仅总结用户消息，摘要前显示询问、想法、需求、反馈、确认中的主要意图。标签使用灰玫瑰配色，按该顺序由浅到深显示。结合上下文识别承接设想的“开始做”为需求。旧地图刷新时补齐缺失标签，复用摘要、话题和原文标识。
- 新摘要按短标题生成，提示词要求以核心动作或问题与关键对象概括，目标 12—24 字，通常不超过 32 字。保留影响含义的关键限制，省去意图前缀、背景铺垫和诊断过程。已有摘要在增量更新时继续复用。
- 顺序相邻不自动代表父子关系。
- 面板首次挂载、切换聊天或点击「更新地图」时，读取当前会话投影，与已保存消息 id 比较，只总结新增消息。旧地图缺少话题或意图字段时，会调用当前模型补齐分类，复用已有摘要、原文与定位标识。已挂载面板隐藏后再次显示时可能直接展示缓存，发送新消息后请点击「更新地图」。
- 模型调用使用 Harness 已选的模型和已登录的供应商适配器，不需要 Codex 账号。
- 话题与意图字段齐全且没有新增消息时直接读取已保存地图。并发刷新复用同一任务，每批摘要校验通过后持久化。
- 点击节点按原始事件序号补载历史，再定位插件在对应原生用户消息中注册的标记。定位不调用模型。
- 使用 Harness Storage Domain 保存每个会话的地图，不把摘要回写主聊天，也没有自动五轮触发。

## 安装

从 [0.5.0 Release](https://github.com/dickens2685477697-dotcom/Understanding-Map/releases/tag/v0.5.0) 下载 `Understanding-Map-DeepSeek-0.4.0.zip`，解压到准备长期保留的位置，按包内 `START-HERE.md` 安装。

在 Harness 中使用其原生 `plugin_manager` 工具：

```json
{"action":"install_bundle","target":"/absolute/path/to/Understanding-Map/deepseek-harness"}
```

其他电脑改成自己的绝对目录。通过应用的审批后安装；不需要手改 `~/.dsh/profiles`。更新已经加载的插件代码后，按 Harness 提示重启。

## 使用

安装一次后正常打开 Harness，在聊天顶部点击「理解地图」。面板首次加载会为该聊天生成地图，后续发送新消息后，底部会提示待更新数量，点击「更新地图」后等待「地图已更新」或「已是最新」。使用「按层级」和「按时间」切换阅读方式，直接点击摘要返回原文，包括很短的消息。视图、话题折叠和选择状态会按聊天保存。

在地图顶部选择标签，可集中查看询问、想法、需求、反馈或确认。时间视图中的「已隐藏 N 条」可展开检查未匹配发言，再次点击收起；选中结果与展开后的发言都沿用原始标识返回原文。筛选不会触发「更新地图」。

链接安装需要保留插件目录。插件管理器中可查看版本或停用插件。它不依赖 Codex 账号或 Codex 的本机导航辅助服务。
