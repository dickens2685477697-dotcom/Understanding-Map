# Understanding Map for DeepSeek Harness

独立的 Harness 原生插件，包名 `@local/understanding-map-deepseek`。源码与现有 Codex 版本分开。

## 功能

- 聊天标题栏提供「理解地图」按钮，在 Harness 右侧打开原生 React 面板。
- 「按层级」按话题组织可折叠大纲，编号保留原始发言顺序。
- 「按时间」使用与 Codex 端相同的 48px 行高、22px 层级缩进和节点样式。灰色虚线连接时间顺序，蓝色实线连接已有的消息承接。
- 话题的概念层级决定横向位置和蓝色深浅。顶层靠左、深蓝，子层向右、颜色变浅。
- 仅总结用户消息；顺序相邻不自动代表父子关系。
- 打开面板或点击「更新地图」时，读取当前会话投影，与已保存消息 id 比较，只总结新增消息。旧版地图首次打开时会调用当前模型补齐话题归类，保留已有摘要、原文与定位标识。
- 模型调用使用 Harness 已选的模型和已登录的供应商适配器，不需要 Codex 账号。
- 话题归类完整且没有新增消息时直接读取已保存地图。并发刷新复用同一任务，每批摘要校验通过后持久化。
- 点击节点按原始事件序号补载历史，再定位插件在对应原生用户消息中注册的标记。定位不调用模型。
- 使用 Harness Storage Domain 保存每个会话的地图，不把摘要回写主聊天，也没有自动五轮触发。

## 安装

在 Harness 中使用其原生 `plugin_manager` 工具：

```json
{"action":"install_bundle","target":"/absolute/path/to/Understanding-Map/deepseek-harness"}
```

其他电脑改成自己的绝对目录。通过应用的审批后安装；不需要手改 `~/.dsh/profiles`。更新已经加载的插件代码后，按 Harness 提示重启。

## 本地检查

```sh
node --test core.test.js
node --check client.js
```

当前插件版本为 `0.2.0`，已在 macOS 的 Harness `0.2.2-rc.1` 中完成实测。两种视图、时间虚线与承接实线、蓝色层级、话题折叠、旧地图归类迁移、4→5 条真实增量更新和原生定位均通过。正常退出并重开应用后，地图、视图选择、折叠状态和原文选择均恢复，短消息仍能点击定位。

当前验证范围：macOS 桌面、对话视图、普通用户文字消息。Windows、英文界面实际渲染、超长历史分页、附件单独消息尚未完成实机验收。请保持原生「对话」视图打开后点击地图节点。

已使用应用随附的实际运行时完成隔离测试：`runtime-smoke.mjs` 验证会话投影、客户端快照、JSON 持久化和重新读取。测试只创建临时目录，不使用个人会话或凭据。

## 使用

安装一次后正常打开 Harness，在聊天顶部点击「理解地图」。首次打开会为该聊天生成地图，后续发送新消息后点击「更新地图」。使用「按层级」和「按时间」切换阅读方式，直接点击摘要返回原文，包括很短的消息。视图、话题折叠和选择状态会按聊天保存。

本机是链接安装，源码目录需要保留。插件管理器中可查看版本或停用插件。它不依赖 Codex 账号或 Codex 的本机导航辅助服务。
